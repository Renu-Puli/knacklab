# Module 01 - CONTEXT: Hypothesis-First Debugging

- **Skill**: Debugging & Incident Response (`debugging-incident-response`)
- **Module**: 01
- **Step**: CONTEXT
- **Incident Overview**:
  - URL shortener service crashes on startup with broken links and no runbook or handoff.
  - Core philosophy: Avoid "shotgun debugging" (blind code edits, random config modifications, guessing).
  - Adopt hypothesis-first differential diagnosis: Observe Symptom -> Formulate Testable Hypothesis -> Run Targeted Test -> Eliminate or Confirm Root Cause.
