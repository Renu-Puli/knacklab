1. ROOT CAUSE
--------------------------------------------------------------------------------
The injected configuration in `apps/api/app/config.py` defined:
`api_key_a: str = Field(..., alias="API_KEY_PRIMARY")`
This made `API_KEY_PRIMARY` a mandatory environment variable alias. However, the application's environment configuration (.env) supplies `api_key_a` (as `API_KEY_A`), not `API_KEY_PRIMARY`.

During startup, Pydantic's `BaseSettings` validation detected the missing required field and raised a `ValidationError`, which was intercepted by the startup safety guard in `config.py` and converted to a `RuntimeError: Startup Configuration Error: Invalid or missing environment configuration.`

This fail-fast validation behavior is an essential production pattern: it prevents services from starting up silently with missing, malformed, or unconfigured authentication credentials.
